# 作り物のプリント

試すときに使う、作り物の書類です。学校・幼稚園・会社・お店の名前は、すべて架空です。

| ファイル | 中身 | 試せること |
|---|---|---|
| `01_学年だより_11月号.pdf` | みどり小学校 2 年の学年だより。表に行事と持ち物 | 名付け・持ち物の取り出し |
| `02_校外学習のお知らせ.pdf` | 11/11（水）の校外学習。持ち物と雨天時 | 予定の取り出し・明日のお知らせ |
| `03_11月の行事予定.pdf` | 1 か月分の行事予定表（表） | 表の読み取り（3 章） |
| `04_11月の給食献立.pdf` | 1 か月分の給食献立表（表） | 献立（5 章） |
| `05_えんだより_11月.pdf` | ひかり幼稚園のえんだより。お弁当の日 | 幼稚園の書類の振り分け |
| `06_食器洗い乾燥機_取扱説明書.pdf` | 架空の家電の取扱説明書（抜粋） | プリント以外の紙・検索 |
| `07_食器洗い乾燥機_保証書.pdf` | 同じ家電の保証書 | 「保証はいつまで？」 |
| `08_算数テスト_ひき算のひっ算.pdf` | 2 年の算数のテストの答案。赤ペンの丸付きで 80 点（10 問中 2 問まちがい。どちらもくり下がり） | 復習問題づくり（本の応用の章） |

`scan/` には、同じ書類を「スキャンしたような画像」（少し傾けて色を薄くしたもの）で入れてあります。PDF は最初から文字が入っているので、OCR を試したいときは `scan/` の画像を使ってください。

```bash
# 例：行事予定表と校外学習のお知らせを取り込む
cp samples/02_校外学習のお知らせ.pdf samples/03_11月の行事予定.pdf paperless/consume/
```

作り直すときは `python3 samples/build.py`（Chrome と日本語のフォント、Pillow が要ります）。
